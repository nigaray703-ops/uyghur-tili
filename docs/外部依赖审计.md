# Uyghur Tili 国内版外部依赖审计

审计范围：国内版 `site/` 源码、构建脚本以及最终 `dist-cn/` 中的 HTML、CSS 和 JavaScript。

## 运行时结论

- 国内版 `index.html` 不加载 Vercel、jsDelivr、Google Fonts 或 Supabase SDK。
- JavaScript、CSS、Logo、网站图标、课程数据和真人音频均从 `dist-cn` 内以相对路径加载。
- CSS 使用设备自带的系统字体栈，不发起字体网络请求。
- 学习进度使用浏览器 `localStorage`，导入和导出使用本地 JSON 文件。
- 页面运行时不会请求国外版网址；`https://ana-tilim.vercel.app` 只作为项目说明中的国外版地址。
- 唯一获准的外部运行时请求是匿名反馈提交：`feedback.js` 直接向固定的 Supabase REST 表端点发送文字反馈；不加载 Supabase SDK，不传附件，学习进度仍只保存在本地。

## 从国外版移除的运行时依赖

- jsDelivr 上的 `@supabase/supabase-js`
- Supabase 登录、云同步客户端与 SDK（仅保留匿名反馈所需的固定 REST 端点和公开提交密钥）
- 注册、登录、Google 登录、邮箱验证码和云端同步脚本入口
- 国内版源码中的 `cloud-config.js`、`cloud-sync.js` 和 Supabase 数据库结构

## 本地化资源

- 核心 JavaScript：`app.js`、课程数据、转写、逐词词素标注、真实维吾尔语键盘、进度导入导出、音频控制器
- CSS：`styles.css`
- Logo：`assets/logo.png`
- 网站图标：`assets/favicon-32.png`、`assets/apple-touch-icon.png`、`assets/icon-192.png`、`assets/icon-512.png`
- 真人录音：`assets/audio/human/**/*.webm`
- 字体：系统字体栈，无 Google Fonts

## 发布包检查规则

- 所有 `href`、`src` 和音频输出路径必须以 `./` 开头。
- 除 `feedback.js` 中批准的单一匿名反馈 REST 端点外，HTML、CSS 和 JavaScript 中不得出现 `http://`、`https://`、jsDelivr、Google Fonts、Supabase 或 Vercel 运行时地址。
- `dist-cn/index.html` 必须位于发布包最外层。
- 国内版不打包已隐藏的名人名言专用音频。

## 不属于国内版运行时的链接

Ana Tilim 仓库文档中的 GitHub、Vercel 和课程资料来源链接只用于开发文档，不会进入 `dist-cn` 或被学习网站加载。
