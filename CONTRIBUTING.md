# Feedback and contribution boundary

Uyghur Tili is an independent portfolio project. It is not a community or
collaborative open-source project.

## Feedback

Factual corrections, broken links, audio problems, accessibility issues, display
problems, and security concerns may be reported through the feedback function on
the official website or through the owner's official GitHub account.

## Code contributions

Unsolicited pull requests, source-code contributions, copied course materials,
replacement branding, and audio uploads are not accepted. Only the project owner
decides whether and how a correction enters the official private source,
deployment, or public showcase.

Feedback, suggestions, corrections, discussions, pull requests, or forks do not
grant permission to copy, modify, redistribute, rehost, or reuse the project or
its human recordings. See [LICENSE.md](./LICENSE.md).
