## 项目介绍

Uyghur Tili 是面向中国大陆访问环境的维吾尔语学习网站。学习者无需注册即可使用主要课程，
学习进度默认保存在当前浏览器，并可由学习者手动导出和导入。

The project is a China-focused Uyghur language learning website with guided
practice, browser-local progress, right-to-left text support, and human
pronunciation audio available only through the official website.

## 项目目标

- 将字母识别、连接形态、发音、词汇、听力、阅读、书写和键盘输入组织为连续学习路径。
- 降低零基础学习者进入维吾尔文字母和从右到左书写系统的门槛。
- 在中国大陆版本中减少海外运行依赖，不要求登录或云端同步。
- 为手机浏览器提供清晰、可重复练习的学习流程。

## 已实现的体验

- 维吾尔文字母、连接形式、发音提示和 ULY 拉丁转写。
- 词汇、常用组合、例句、阅读、听写、配对与错误回顾。
- 维吾尔语键盘和拉丁输入练习。
- 逐词释义、词素参考和基础句型学习。
- 手机优先布局、从右到左文字支持和浏览器本地进度。
- 学习记录导出、导入与恢复。
- 通过正式网站播放的真人发音。

## 技术概览

正式网站采用浏览器端 HTML、CSS 和 JavaScript，实现课程路由、交互练习、本地进度、
键盘输入、音频播放和响应式布局。国内版发布流程生成不包含海外登录与云同步模块的静态站点，
再部署到 Tencent CloudBase。

本公开仓库不提供可克隆运行的源码、构建包、数据库配置或音频文件。

## 数据与隐私

- 国内版不要求注册或登录。
- 昵称、头像和学习进度默认保存在访问者自己的浏览器中。
- 学习者可以自行导出和导入学习记录。
- 网站反馈只在学习者主动提交时发送填写的反馈内容和可选联系方式。
- 真实用户导出、数据库备份、凭据和私有配置不会进入公开仓库。
